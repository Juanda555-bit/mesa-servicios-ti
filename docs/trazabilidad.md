# Matriz de trazabilidad

Esta matriz relaciona cada condición de aceptación (CA) con su requisito, su implementación, su pull request y su prueba. Una condición se cumple cuando tiene implementación y prueba. La columna "Pull request" registra en qué PR se integra el cambio, como evidencia del trabajo colaborativo que piden las Actividades 5 y 7 de la guía. Hoy existen la capa de datos (`backend/db/`), la API REST con la seguridad y las capas de la spec 002 y la interfaz web React de la spec 003 (`frontend/`), con 85 pruebas pytest. La prueba funcional PF-12 recorre el flujo completo por la interfaz (CA-01..CA-06); las pruebas funcionales PF-01..PF-11 por la interfaz siguen "Por completar" (spec 004).
