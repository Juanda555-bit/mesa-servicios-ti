# Matriz de trazabilidad

Esta matriz relaciona cada condición de aceptación (CA) con su requisito, su implementación, su pull request y su prueba. Una condición se cumple cuando tiene implementación y prueba. La columna "Pull request" registra en qué PR se integra el cambio, como evidencia del trabajo colaborativo que piden las Actividades 5 y 7 de la guía. Hoy existen la capa de datos (`backend/db/`) y la API REST (sin interfaz) con la seguridad y las capas de la spec 002 (76 pruebas pytest); las pruebas funcionales y de interfaz siguen "Por completar".
